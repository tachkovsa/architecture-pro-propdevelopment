# Проверочный лист безопасности для PropDevelopment

## Обоснование структуры проверочного листа

На основе анализа проблем компании и специфики бизнеса выбраны следующие ключевые направления проверки:

* **Управление доступом** — критически важно для защиты от несанкционированного доступа к данным клиентов и систем
* **Безопасность API** — учитывая множественные интеграции между системами и внешние API
* **Защита данных** — для предотвращения утечек персональных данных
* **Безопасность приложений** — учитывая наличие веб- и мобильных решений
* **Соответствие требованиям** — для соблюдения законодательства в сфере ПДн
